# 📺 VidStream

---

## 🔷 Introduction

VidStream is a full-stack video streaming web application that allows users to browse, discover, and watch video content with ease.

This project was created to simulate a modern streaming platform (like YouTube®) focusing on seamless video playback, user interaction, and clean UI/UX design.

---

## 🛠️ Technologies Used
 
- Node.js
- Express.js  
- MongoDB
- Custom Routes  
- Cloudinary

---

## ⚙️ The Process (How I Built It)

1. **Server Setup:** Built a backend using Node.js and Express for routing
2. **Database Design:** Connected MongoDB to store video metadata and user info.\
3. **Optimizations:** Ensured performance-friendly loading for video content.

This project helped build understanding of video streaming protocols and backend media delivery.

---

## 📚 What I Learned

- Serving media efficiently with Node.js
- Backend routing for large file handling
- Structuring a full-stack application
- Integration of database with media playback

## 💻 How to Run the Project

### Prerequisites

- Node.js
- npm
- MongoDB

### Installation Steps

```bash
# Clone the repository
git clone https://github.com/sarthak-sharma31/VidStream.git

# Navigate into the project folder
cd VidStream

# Install dependencies
npm install

# Start the server
npm start
```

The application will run at:

```
http://localhost:3000
```

Ensure your database is running before starting the application.
